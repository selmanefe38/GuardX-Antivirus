# 🛡️ GuardX Ultimate Antivirus v18.0

Avast ve onun gibi reklam dolu, hantal ve sadece şov yapan antivirüslere tepki olarak **sadece 2 günde** geliştirilmiş, hafif ve nokta atışı çalışan siber güvenlik projesi.

## ✨ Öne Çıkan Özellikler
- **Cerrah Tipi Kod Analizi:** Dosyaları sadece dışarıdan taramaz; binary (byte) seviyesinde açarak sinsi Powershell komutlarını ve tehlikeli Windows API çağrılarını (`VirtualAlloc`, `CreateRemoteThread` vb.) ameliyat eder gibi yakalar.
- **Shannon Entropi Analizi:** Crypter ile şifrelenmiş veya sıkıştırılmış (Ransomware vb.) şüpheli exeleri karmaşıklık oranından tespit eder.
- **Yapay Zeka Sandbox Simülasyonu (Modül 18):** Şüpheli dosyaları sanal bir risk analizine tabi tutar.

## 🚀 Nasıl Çalıştırılır?
Proje C# (Windows Forms) ile yazılmıştır. `Form1.cs` kodunu Visual Studio üzerinde yeni bir Windows Forms projesine yapıştırarak hemen derleyebilir ve kendi antivirüsünüzü çalıştırabilirsiniz.
